دعوة حنة نورهان
================
ملفات الموقع مسطحة وجاهزة للرفع على GitHub Pages.

طريقة الاستخدام:
1) ارفعي كل الملفات الموجودة داخل ملف ZIP إلى جذر المستودع (Root) في GitHub.
2) تأكدي أن اسم الصفحة الرئيسية هو index.html.
3) فعّلي GitHub Pages من Settings > Pages إذا لم يكن مفعلاً.

التفاعلات:
- زر "فتح دعوة العروسة" في الغلاف يفتح الصفحة الثانية.
- "بيت العروسة" يفتح رسالة خصوصية ثم زر واتساب للرقم المحدد.
- زر التاريخ يعرض اليوم والموعد.
- "كلمة حلوة للعروسة" يفتح جروب الواتساب المرسل.
- "تأكيد حضور" يفتح واتساب برسالة تأكيد جاهزة.
